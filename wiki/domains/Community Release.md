# Community Release

This domain covers turning the tool into something the Legends / Skool community can actually use.

## Release Promise

Give operators a clear, Windows-first way to run lawful archive jobs without accidental non-VPN traffic, lost progress, or mystery command-line failures.

## Packaging Goals

- One installer or portable bundle.
- Guided first-run setup checks.
- Clear preflight report before any network work.
- Example batch templates.
- Human-readable completion reports.
- No hidden bypass behavior.

## Community Docs Needed

- Install guide.
- "What this tool is and is not" page.
- Example lawful workflows.
- Troubleshooting guide.
- Changelog and release notes.
