# Telemetry and Reports

## Purpose

Make every batch explainable after the fact.

## Report Contents

- Batch id.
- Source URL.
- Rights basis.
- Operator profile.
- Start and end times.
- VPN preflight evidence.
- yt-dlp version and config profile.
- Counts: planned, done, skipped, failed, blocked.
- Stop condition if any.
- Download archive path.
- Output folder path.

## Privacy Rule

Reports should avoid storing account cookies, secrets, auth tokens, or full private URLs unless explicitly needed and protected.
