# Batch Archive SOP

## Goal

Run a lawful archive batch with clear evidence and resumable state.

## Procedure

1. Create a batch plan.
2. Record the rights basis.
3. Run preflight.
4. Review planned output path and disk requirements.
5. Start the batch.
6. Monitor item counts and stop-condition messages.
7. If paused or blocked, follow [[Blocked or Throttled SOP]].
8. On completion, review the final report and archive file.

## Verification

- Final report exists.
- Download archive exists.
- Counts match expected item count or explain differences.
- Failed and skipped items are listed.
