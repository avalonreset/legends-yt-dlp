# Code of Conduct

## Our Standard

This project expects direct, respectful collaboration focused on lawful archival
work, operator safety, and practical engineering quality.

Unacceptable behavior includes harassment, abusive conduct, doxxing, credential
sharing, or requests to build bypasses for platform controls.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict
participation when behavior violates this standard or the project's safety
boundary.

Report concerns privately to the maintainers through the Avalon Reset Pro
GitHub organization.
